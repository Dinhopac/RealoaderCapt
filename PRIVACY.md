# Privacy Policy for ReloaderCapt Pro

Last Updated: November 2026

## Overview

ReloaderCapt Pro is a browser extension designed to monitor web page changes, perform automated page reloads and notify users when configured monitoring conditions are met.

## Data Collection

ReloaderCapt Pro does not collect, transmit, sell, rent, share or store personal information on external servers.

The extension operates locally within the user's browser.

## Information Stored

The extension may store the following information locally using the browser storage API:

- Monitoring rules
- CSS selectors
- XPath expressions
- Reload intervals
- Dashboard settings
- User preferences

This information remains on the user's device and is not transmitted to the developer.

## Website Access

The extension accesses web pages selected by the user solely to:

- Monitor content changes
- Inspect configured elements
- Execute reload operations
- Trigger user notifications

No browsing history is collected or transmitted.

## Third Party Services

ReloaderCapt Pro does not use analytics services, advertising services, tracking tools or external data collection systems.

## Data Sharing

ReloaderCapt Pro does not:

- Sell user data
- Share user data with third parties
- Transfer user data for advertising purposes

## Security

All extension functionality executes locally within the browser and does not communicate with remote servers for monitoring activities.
